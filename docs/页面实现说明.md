# 页面实现说明

本项目使用 **Kuikly 跨端框架**实现 UI，采用声明式 DSL 编写页面，而非传统的 XML 或 Compose。

## 核心页面实现

项目包含 **3 个主要页面**（使用 `@Page` 注解注册）：

### 1. 行情首页 (StockHomePage.kt)
- **注解**: `@Page("stock_home")`
- **文件大小**: 28KB，约 800 行代码
- **功能**:
  - 市场概览（涨跌统计、指数行情）
  - 股票列表（支持搜索、排序）
  - 自选股/持仓股切换
  - 实时数据刷新

### 2. 个股详情页 (StockDetailPage.kt)
- **注解**: `@Page("stock_detail")`
- **文件大小**: 26KB，约 750 行代码
- **功能**:
  - 实时行情数据（价格、涨跌、成交量）
  - 多周期走势图（分时、5日、日K、周K、月K）
  - AI 分析预览
  - 买入/卖出/关注操作

### 3. AI 分析页 (StockAiPage.kt)
- **注解**: 通过路由跳转访问
- **文件大小**: 3.9KB
- **功能**:
  - 结构化 AI 分析展示
  - 趋势判断、观察计划、风险提示

## 技术架构

### Kuikly 框架特性
- **声明式 DSL**: 使用 Kotlin DSL 编写 UI
- **跨端渲染**: 一套代码支持 Android/iOS/HarmonyOS
- **响应式数据**: `observable` 和 `observableList` 实现数据绑定
- **组件化**: `ViewBuilder` 构建可复用组件

### 页面注册机制
```kotlin
@Page("stock_home", supportInLocal = true)
internal class StockHomePage : BasePager() {
    // 页面逻辑
}
```

### 数据流
```
用户交互 → Page → Repository → SQLDelight/Network → 数据更新 → UI 自动刷新
```

## 为什么找不到传统的 .kml 或 Screen.kt？

**Kuikly 框架不使用传统的 Android View 体系**：
- ❌ 不是 Compose（所以没有 `@Composable` 和 `@Preview`）
- ❌ 不是 XML 布局（所以没有 `.kml` 配置）
- ✅ 使用自己的 DSL 语法直接在 Kotlin 代码中构建 UI
