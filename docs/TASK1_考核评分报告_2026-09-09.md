1. **先修 Android D8 构建失败**：必须生成并安装 Debug APK，录制首页 → 详情 → 图表切换 → AI 解读 → 返回的连续视频。
2. **修复 JS test 编译失败**：至少让 `:shared:allTests` 通过；否则跨端工程的“可运行”不能成立。
3. **补页面级验证**：覆盖路由参数缺失、详情不存在、首页失败后重试、AI 为空、自选跨页同步、长文本/窄屏。
