## 四、技术架构证明

### 4.1 Kuikly 框架使用

项目使用 **Kuikly 跨端框架**实现 UI，而非传统的 Compose 或 XML：

```kotlin
@Page("stock_home", supportInLocal = true)
internal class StockHomePage : BasePager() {
    // 使用 Kuikly DSL 构建 UI
    override fun build(): View = ...
}
```

**为什么找不到 .kml 文件？**
- Kuikly 使用 Kotlin DSL 直接编写 UI
- 不需要 `.kml` 配置文件或 XML 布局
- 所有 UI 逻辑都在 `.kt` 文件中

### 4.2 数据持久化

使用 **SQLDelight** 实现本地缓存：
```
shared/src/commonMain/sqldelight/com/example/kuiklyaistock/db/
├── StockQuote.sq

├── IntradayTrend.sq

```
